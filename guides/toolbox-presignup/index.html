툴박스 사전 신청 안내 문구

P0기한 이번 주

왜 지금

결제 심사 전이라 돈은 못 받지만 '기다리는 사람'은 지금 모을 수 있다.

준비물

  • 툴박스 사이트 가입 페이지(luke-toolbox.vercel.app)
  • 창립멤버 조건(연 10만, 100명 한정) 확정 여부

순서

  1. 1. 문구 3줄
    무엇(프로그램 구독) · 언제(결제 오픈 예정, 심사 후) · 지금 할 일(가입해두면 오픈 알림+창립가).
  2. 2. 사전 신청 = 회원가입
    별도 폼 대신 사이트 가입으로 통일. 가입자 수가 곧 대기자 수.
  3. 3. 오픈채팅 답변 + 고정 공지
    문의자에게 먼저 보내고, 카톡방 공지로 올리기.
  4. 4. 결제 심사 상태 확인
    토스페이먼츠 심사 진행 상황 주 1회 체크.

끝난 기준

안내 문구가 카톡방 공지에 있고, 가입자 수를 매주 기록.
